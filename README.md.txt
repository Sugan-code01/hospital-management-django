# Hospital Management System (Django + MySQL)

## Description
Entry-level Hospital Management System built using Django and MySQL.
The project supports patient, doctor, and appointment management with CRUD operations and Django admin panel.

## Technologies Used
- Python
- Django
- MySQL
- HTML

## Features
- Add / View / Update / Delete Patients
- Add / View Doctors
- Appointment Scheduling
- Search Patients
- Django Admin Panel
- MySQL Database Integration
